## 🚀 Proyecto destacado

### 📚 aprendeCode

**Aprender a programar también significa aprender de los errores.**

aprendeCode es una plataforma educativa de programación que estoy desarrollando para ayudar a estudiantes a comprender su código, identificar errores y aprender de manera más intuitiva.

**¿Qué ofrece el proyecto?**

- 🔍 Análisis de código Java y detección de errores.
- 💡 Explicaciones claras y pistas progresivas.
- ▶️ Visualización paso a paso del funcionamiento del código.
- 📊 Representaciones visuales de arrays y listas.
- 📚 Aprendizaje guiado para fomentar la autonomía del estudiante.

**Tecnologías:** `Java` `HTML` `CSS` `JavaScript`
